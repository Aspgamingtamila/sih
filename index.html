WeatherGPT

MoES · IMD concept prototype

Ask about forecasts, warnings or advisories in plain language — by typing or by voice.

How this prototype works
Query understanding & multilingual response generation: an LLM (Gemini 3.5 Flash).
Live weather & 16-day forecast data: Open-Meteo global NWP blend (GFS/ICON/others) — a stand-in for direct GFS/WRF + WIS2.0 ingestion in a production IMD deployment.
Alert thresholds: computed locally from forecast fields (rain, gusts, heat/cold) using indicative IMD-style thresholds — not official warnings.
Voice input/output: browser Web Speech API, for low-literacy / rural accessibility.
Production path: FastAPI/Node backend, WIS2.0 + MQTT ingestion, PostgreSQL/PostGIS, containerised on Kubernetes, official IMD warning feed as the alert source of truth.
